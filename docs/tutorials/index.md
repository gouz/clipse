# Tutorials

Tutorials are **learning-oriented**: they take you by the hand through a series of
steps to build something, so you learn by doing.

If you are brand new to clipse, start here:

- **[Build your first CLI](/tutorials/first-cli)** — install clipse and grow a
  small CLI from an empty file to one with options, an argument, and a
  subcommand, running it at every step.

Once you are comfortable, move on to the [How-to guides](/how-to/) for
task-focused recipes, or the [Reference](/reference/) for the exact API.
