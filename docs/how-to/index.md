# How-to guides

How-to guides are **task-oriented**: each one shows how to solve a specific
problem. They assume you already know the basics — if not, start with the
[tutorial](/tutorials/first-cli).

- **[Add options](/how-to/options)** — string and boolean flags, shorthands,
  defaults, and optional options.
- **[Add arguments](/how-to/arguments)** — positional arguments and how they map
  into `args`.
- **[Add subcommands](/how-to/subcommands)** — nest commands to any depth.
- **[Set a default command](/how-to/default-command)** — run a command when none
  is given.
- **[Share global options](/how-to/global-options)** — options inherited by
  subcommands.
- **[Generate shell completion](/how-to/completion)** — ship a bash completion
  script.
- **[Compile a standalone binary](/how-to/compile)** — turn your CLI into a
  single executable with Bun.
